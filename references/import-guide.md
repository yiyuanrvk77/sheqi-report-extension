# 记录导入指南

## 支持格式（自动识别，不看扩展名）

- **JSON**：`{"records":[{...}]}` 或 `[{...}]`；兼容旧 `extension_records.json`（字段：`url/content/platform/account/date/source_status/evidence_type`）。
- **CSV / TSV / 分号分隔**：带表头；表头任意命名，按别名模糊匹配。
- **Excel**：`.xlsx` 首个工作表，第一行为表头。
- **粘贴文本**：直接把表格内容粘贴给 `import` 命令，同样自动识别；粘贴内容会保存到 `sheqi_data/paste_*.txt` 便于复查。

文件扩展名错误不影响识别：内容是 Excel 就按 Excel 解析、内容是 CSV 就按 CSV 解析（按文件头魔数 + 内容嗅探，而不是扩展名）。

- 表头不一定在第一行：前 12 行内自动定位真正的表头行（兼容上方有标题行/说明行）。
- Excel 多 sheet：自动选择表头最像的那个 sheet。
- 加 `--show-map` 可打印识别到的列映射，便于核对。
- 识别不到“链接/网址”列时会明确报错并列出表格可用列。

## 列名别名

| 标准字段 | 别名（不区分大小写） |
|---|---|
| `url` 链接 | 链接、网址、URL、link、举报网址、原始链接、原文链接、原文地址、稿件链接、新闻链接、帖子地址、网页链接、地址、文章链接、网络链接、帖子链接、源链接、路径 |
| `title` 标题 | 标题、title、文章标题、标题名称、新闻标题、文章名、题目 |
| `body` 正文 | 正文、内容、摘要、描述、body、content、正文内容、文章内容、内容摘要、文章摘要、正文摘要 |
| `media` 媒体名称 | 媒体名称、平台名称、媒体、来源、平台、media、source、网站名称、自媒体名称、发布媒体、新闻来源、媒体来源、发布平台、所属平台、平台类型 |
| `author` 作者 | 作者、作者名称、发布者、博主、author、发布人、作者名 |
| `account` 账号 | 账号、账号名称、平台账号、account、媒体账号 |
| `date` 日期 | 日期、发布时间、发布日期、时间、date、发表日期、接收时间、接收时间（火山） |
| `status` 状态 | 状态、链接状态、内容状态、status、是否转发 |

表头完全匹配不到时，按标准 7 列顺序回退：`日期, 标题, 正文, 媒体名称, 链接, 作者, 状态`。

## 已知兼容性注意

- **Excel 日期序列号**：部分 WPS/导出表的"发布时间"列是 Excel 序列号（如 `45657.63`），导入前需先转成 `YYYY-MM-DD`（用公式或脚本换算），否则记录日期会变成数字。
- **openpyxl 解析失败**：个别 WPS 生成的 xlsx 样式表不规范，`openpyxl.load_workbook` 可能报 `Fill() takes no arguments` 等错误。此时先用 zipfile 直解 XML 或另存为 CSV 再导入（识别按内容魔数，不看扩展名）。
- **链接列名非"链接"**：如列名叫"路径/地址/源链接"等，别名表已覆盖；若仍识别不到，`import --show-map` 会列出表格可用列辅助排查。

## 必需字段与默认值

- **必需**：`url`（必须 http(s) 开头，否则跳过）。
- `title` 缺省 → 用链接末段或“未知内容”。
- `media` 缺省 → 用 `platform` 或“未知平台”；`account` 缺省 → 用作者或媒体名。
- `date` 缺省 → 导入当天；`status` 缺省 → “未标注”。

## 自动过滤与去重

- 状态含“转发 / 已删除 / 已失效” → 跳过（并记录原因）。
- 重复链接（去尾部 `/` 后比较）→ 跳过。
- 举报内容由模板生成并严格截断到 ≤500 字，超出部分记录提示。

## 材料文件扩展名修正

注册主体材料时（`subject add --file 键=路径`），脚本会把文件复制到 `sheqi_data/documents/<主体名>/`，并按文件头魔数（JPEG/PNG/PDF/GIF）自动补正扩展名（例如把内容为 PNG 却叫 `.jpg` 的文件存为 `.png`），避免上传时被拒。

## 示例

```csv
发布时间,标题,正文,来源,链接,作者,状态
2026-08-07,标题A,正文内容A,微博,https://weibo.com/xxx,作者A,
```

```json
{"records": [
  {"url": "https://mp.weixin.qq.com/s/xxx", "title": "标题B", "platform": "微信公众号", "date": "2026-08-07"}
]}
```
